🔊 語音功能設定

開啟後，NPC 可用語音朗讀回覆，玩家也能用語音輸入文字。若玩家裝置缺少指定語音，系統會自動改用可用的語音。語音輸入的麥克風權限只會請求一次（需在 HTTPS 或 localhost 環境；直接用 file:// 開啟瀏覽器會每次詢問，這是瀏覽器安全限制）。

此清單為您本機瀏覽器可用的語音；匯出後將以「語音名稱」比對玩家裝置，找不到時自動退回中文預設語音。

🖼️ 圖片資源庫

為每張圖片設定「觸發關鍵字」與「說明文字」。當玩家的問題提到相關關鍵字時，NPC 會在回覆中秀出該圖並以文字呼應。

📍 GPS 定位引導點

設定地點座標與偵測半徑。當玩家在範圍內提問時，NPC 會先給固定的抵達引導語，並額外套用「引導方向」來調整回答（原始回答原則仍然生效）。可按「測試我的定位」檢查目前裝置與各定位點的距離是否正確。

📝 對話紀錄 (含絕對時間戳記)

所有對話會自動存在玩家本機 (名稱「對話紀錄」) 並帶入每次回覆的脈絡參考。勾選以下項目，玩家介面就會出現對應按鈕。

💬 NPC 主動發言

開啟後，NPC 會依「每隔幾句話」或「每隔幾分鐘」，根據目前對話紀錄與你設定的指示主動說話（兩個條件先到者觸發）。

條件觸發規則 (選填)

當玩家的句子包含特定單詞時，NPC 會執行對應動作 (固定回答不消耗 API 額度)。
